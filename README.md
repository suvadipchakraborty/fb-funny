# Comment Comedian
1. Get a free key: https://aistudio.google.com/apikey
2. Push this folder to a GitHub repo, import it at vercel.com (Framework: Other).
3. In Vercel > Settings > Environment Variables add:
   GEMINI_API_KEY (required), APP_PASSWORD (recommended), GEMINI_MODEL (optional, default gemini-2.5-flash)
4. Deploy, open the URL on your phone, Chrome menu > Install app.
